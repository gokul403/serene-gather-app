# Event Glow Dashboard

Build a frontend-only Customer Event Management Web App.

Customers should log in using their mobile number + OTP (use a mock OTP, no backend).

After login, show a clean, modern, premium customer dashboard with:

Dashboard – event name, date, countdown, venue, event status, payment summary, upcoming activities.

My Event – complete event details, venue, date/time, guest count, event manager contact.

Schedule – event timeline with all functions/activities.

Services – booked services such as catering, photography, decoration, makeup, etc., with status and price.

Payments – total amount, paid amount, pending amount, payment history.

Documents – invoices, agreements, receipts with view/download UI.

Gallery – event images with responsive gallery/lightbox.

Support – contact event manager and simple support form.

Profile – customer details and logout.

Design

Create a premium, elegant, modern UI suitable for weddings and events. Use a clean layout, attractive cards, subtle animations, icons, and responsive design.

Technical

Frontend only

Use mock data

No backend/API/database

Use localStorage for mock login persistence

Responsive for mobile, tablet, and desktop

Use reusable components

Include proper navigation/sidebar and mobile menu

Create routes for Login, OTP, Dashboard, Event, Schedule, Services, Payments, Documents, Gallery, Support, and Profile.

Use realistic sample customer and event data so the app looks complete.
